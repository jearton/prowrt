# ProWrt 固件的统一 GHCR 路径

ProWrt 项目只发布一种制品：**定制固件**。2026-11-23 将正式版和 CI 候选的发布路径统一为 `ghcr.io/jearton/prowrt`，不再增加 `/firmware` 分类层级。一个 OCI 固件包包含 EFI 镜像、软件包清单和 SHA256SUMS。

```sh
oras pull ghcr.io/jearton/prowrt:v25.12.6-20261120.2
sha256sum -c SHA256SUMS
```

## CI 和文档

- Release 发布工作流使用 `ghcr.io/${GITHUB_REPOSITORY,,}:版本`。
- 完整构建工作流将固件候选发布为同一路径的 `ci-运行编号-尝试次数` tag。
- 发布后用空 registry 凭据配置、禁用本地 ORAS 缓存，按 OCI 摘要匿名完整拉取并核对镜像、清单和 gzip 完整性。
- README、下载文档和物理机安装文档使用统一路径；独立 `luci-app-technitium` 项目不受影响。
